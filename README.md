# HouseHunter 🏠

## 📝 Temática del Proyecto
HouseHunter es un sistema de gestión y búsqueda de propiedades inmobiliarias. El sistema permite centralizar la interacción entre administradores, empresas del sector e invitados, optimizando la validación de usuarios y la persistencia de datos habitacionales.
